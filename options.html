Grab and favorites

The site's official extension API has no grab action at the moment, so auto-grab can't run (it's kept in case a future API version adds one, and nothing is ever clicked on the page). Auto-star below does the same job inside this add-on. Star a track in the panel (or with Alt+Shift+F) to add it to your favorites.

Mod assist

Works only when your role in a room is in the list below, and switches itself off everywhere else. It detects, alerts, logs and can post chat warnings. It cannot kick, ban, mute or skip: the official wavez.fm extension API has no moderation actions.

Room themes

Restyles wavez.fm in your browser only; nobody else sees it. Changes here apply immediately (no Save needed). You can also pick a theme per room from the in-page panel.
